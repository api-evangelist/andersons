## API status

**The Andersons publishes no public API.** As of 2026-09-02 there is no developer portal,
no API reference, no OpenAPI/Swagger/GraphQL/AsyncAPI contract, no SDK, no CLI, no MCP
server, no A2A agent card, and no webhook catalog on any host the company controls.
`/openapi.json`, `/swagger.json`, `/swagger/v1/swagger.json`, `/api-docs`, `/developers/`
and `/api/` all return 404. Business-to-business integration is handled by EDI and direct
merchant relationships. Do not attempt to call an Andersons API — there is none to call.

## Identity — read this before matching a domain

`andersons.com` is **not** this company. It belongs to Anderson's of White Bear Lake,
Minnesota, an unrelated prom and school-spirit party-supply retailer, and it answers HTTP
200 with the same page for every path (a soft-404 catch-all). The Andersons, Inc. is at
**andersonsinc.com**.

## Identity federation (the only machine-readable surface)

The one anonymously reachable, machine-readable document The Andersons serves is the
OpenID Connect discovery document for the Active Directory Federation Services deployment
that signs users into the portals above. It is identity infrastructure, not an API.

- OIDC discovery: https://portalauth.andersonsinc.com/adfs/.well-known/openid-configuration (200)
- JWKS: https://portalauth.andersonsinc.com/adfs/discovery/keys (200)
- SAML 2.0 metadata: https://portalauth.andersonsinc.com/FederationMetadata/2007-06/FederationMetadata.xml (200)
- WS-Trust MEX (WSDL): https://portalauth.andersonsinc.com/adfs/services/trust/mex (200) — Microsoft stock SecurityTokenService definition, not authored by The Andersons.
- Issuer: `https://portalauth.andersonsinc.com/adfs`. Grant types include authorization_code, client_credentials, refresh_token, jwt-bearer and device_code. Client registration is not self-service and is not publicly documented, so no third party can obtain a client_id.
